# Окно меню эксперимента

```
python -m multiuav menu
```

Окно собирает параметры попытки, показывает значок «пульт подключён» и кнопку «Старт». После
конца попытки остаётся открытым: можно менять параметры и запускать следующую.

На Ubuntu для окна нужен tkinter: `sudo apt install python3-tk`. Значок пульта работает при
установленном pygame: `pip install -e .[gamepad]`.

## Что делает «Старт»

1. Проверяет параметры (понятное сообщение, если что-то не так).
2. Создаёт папку попытки `<папка журнала>/run_<дата_время>/` и пишет туда `experiment.json`
   со всеми параметрами.
3. Запускает сценарий в этом же процессе, как `python -m multiuav run`, и сохраняет `track.csv`
   и `summary.json` (то же, что делает `run --out`).

Когда появится скрипт автозапуска Unreal (`python -m multiuav launch <файл параметров>`), пункт 3
заменяется его вызовом: `experiment.json` уже лежит в папке попытки как раз для него. Место
замены — функция `run_experiment` в `multiuav/experiment.py`.

## Какие параметры что делают

| Поле | Действие |
|---|---|
| Дронов (с ведущим) | число дронов: ведущий + ведомые (то же, что `--followers N` = N+1) |
| Когда конец | «по времени» — ровно столько секунд, финиш сценария отключён; «на финише» — до финишной зоны сценария, длительность служит пределом |
| Режим полёта | AltHold или Acro для ведущего с пульта (как `--mode`); если в сценарии есть `mode_switch`, решает тумблер на пульте; у ведущего-автопилота не действует |
| Сценарий, симулятор, адрес | для отладки; пульт работает только в Cosys-AirSim, Unreal нужно запустить заранее |
| Папка журнала | куда класть папки попыток |

Пока **только записываются** в `experiment.json` (поле `not_applied_yet`) и не влияют на полёт:
длительность затемнения, ветер, камеры ведомых, алгоритмы помощи.
